Debug test pages

Isolated fixtures for UI testing. Each page exercises a specific rendering feature.

Element and style tests

  • elements.html — all HTML block/inline elements
  • css-props.html — colors, borders, text styles, alignment
  • flex.html — flex-direction row/col, justify-content, align-items, flex-grow

Form tests

  • inline-controls.html — checkbox/radio inline with label text (bug: overlap)
  • forms-full.html — all form control types

Navigation tests

  • links.html — inline links, fragment navigation, visited state
  • long.html — tall page for scroll and scrollbar testing
